These docs cover ui-sdk in Ember. Using another framework? See the upstream docs for [React](https://ui-sdk.dev/docs/react), [Vue](https://ui-sdk.dev/docs/vue), [Svelte](https://ui-sdk.dev/docs/svelte), [Solid](https://ui-sdk.dev/docs/solid) or [Web Components](https://ui-sdk.dev/docs/web-components). To build your own components from behaviors, see [Core](https://ui-sdk.dev/docs/core).

`ember-ui-sdk` gives you Glimmer components such as Tabs, Popover, and Select, built on ui-sdk's behaviors. They handle interactions, focus, and ARIA attributes. You choose their markup and styles.

Import a component's root, use the parts it yields, and style them with your own CSS.

## Set It Up

- [Installation](./installation.md): add the package to your Ember app.
- [Components](./components/index.md): browse the components with live examples.
- [Rendering primitives](./rendering.md) and [custom parts](./utilities/custom-parts.md): build your own components from a Core primitive.

## Unofficial

This is a community adapter, not affiliated with Vercel. Core concepts, behaviors and the reference tables live in the [upstream docs](https://ui-sdk.dev/docs).
